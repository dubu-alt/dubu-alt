---
title: README 위젯은 외부 서버가 멈추면 엑박이 된다
date: 2026-11-10
---

통계 카드 같은 README 위젯은 대부분 **남이 운영하는 서버**가 그때그때 이미지를 그려 준다.
그 서버가 멈추면 내 프로필에는 깨진 이미지만 남는다. (실제로 `github-readme-stats` 공용 서버가 503 을 내고 있었다)

- 오래 둘 위젯은 GitHub Actions 로 **내 레포 안에서 직접 생성**하는 쪽이 안전하다 (예: 잔디 뱀 애니메이션)
- 외부 위젯을 쓸 거면 하나가 죽어도 전체가 어색하지 않게 최소한으로만 쓴다
