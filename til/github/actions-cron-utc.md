---
title: GitHub Actions 의 cron 시간은 한국 시간이 아니라 UTC 다
date: 2026-11-10
---

프로필 README 를 매일 자정에 갱신하려고 `0 0 * * *` 를 쓰려다가, 그러면 한국 시간 오전 9시에 돈다는 걸 알았다.

- GitHub Actions 의 `schedule: cron` 은 항상 **UTC 기준**이다. 한국(KST)은 UTC 보다 9시간 빠르다
- 그래서 한국 자정은 UTC 로 전날 15시, `0 15 * * *` 로 써야 한다
- 정해진 시각보다 몇 분 늦게 도는 일도 흔하다 (실행이 몰리는 정각은 특히). 정확한 시각이 중요하면 정각을 피해서 `30 15 * * *` 처럼 잡는다
