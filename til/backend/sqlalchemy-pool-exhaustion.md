---
title: 동시 요청이 몰리면 DB 연결이 바닥나서 서버 전체가 30초씩 멈춘다
date: 2026-10-07
---

AI 챗봇 서버에 채팅이 15건쯤 동시에 들어오면 다른 요청까지 전부 멈춘다는 리뷰를 받고 원인을 찾아봤다.

- SQLAlchemy 는 DB 연결을 **풀(pool)** 에 모아 두고 빌려 쓴다. 기본값은 5개 + 추가 10개 = 최대 15개, 빈 연결을 기다리는 시간은 30초다
- 요청마다 로그인 확인용으로 빌린 연결을 **AI 답변을 기다리는 몇 초 동안 계속 쥐고 있어서** 15건이면 풀이 바닥난다
- 게다가 async 함수 안에서 DB 작업을 동기로 하고 있어서, 연결을 기다리는 30초 동안 서버의 이벤트 루프 전체가 같이 멈췄다
- 다음엔 오래 걸리는 외부 호출(AI API 등) 전에 필요한 값만 꺼내고 `commit()` 으로 연결을 먼저 반납한다. 동기 DB 작업은 이벤트 루프 밖(스레드)에서 돌린다
