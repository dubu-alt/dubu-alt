title: FastAPI 요청은 라우터 → 서비스 → 저장소를 거쳐 다시 화면으로 돌아온다
date: 2026-11-10
---

게시판을 만들면서 브라우저 요청이 서버 안에서 어디를 지나가는지 헷갈려서 정리했다.

- 브라우저와 서버는 **HTTP 요청·응답**만 주고받고, 서버 안에서는 **라우터 → 서비스 → 저장소 → DB** 순서로 내려갔다가 다시 올라온다
- 라우터는 HTTP(`Form`, `RedirectResponse`, `TemplateResponse`)만, 서비스는 검증 같은 **규칙**만, 저장소는 SQLAlchemy로 **DB**만 다룬다
- DB에서 꺼낸 ORM 객체는 서비스에서 **Pydantic 스키마(DTO)** 로 옮겨 담아 라우터에 넘기고, 라우터가 Jinja2 템플릿에 채워 HTML로 응답한다
- 다음엔 "이 코드가 HTTP를 아는가?"로 라우터와 서비스를 나눈다. 그러면 SSR을 REST API로 바꿔도 라우터만 고치면 된다
