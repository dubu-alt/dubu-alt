---
title: FastAPI 의 RedirectResponse 는 기본값이 307 이라 PRG 에는 303 을 직접 써야 한다
date: 2026-11-10
---

글 저장 후 새로고침하면 중복 저장되는 걸 막으려고 PRG(Post-Redirect-Get)를 적용하다가 상태 코드 차이를 알게 됐다.

- 저장 뒤 화면을 바로 그리면 F5를 누를 때 브라우저가 **POST를 다시 전송**해서 같은 글이 또 저장된다. 그래서 저장 뒤에는 다른 주소로 리다이렉트한다
- `RedirectResponse`의 기본 상태 코드는 **307**이고, 307은 **원래 메서드(POST)를 그대로 유지**한 채 다시 요청한다. 상세 주소에는 POST 처리 함수가 없어서 405가 난다
- **303**은 "결과는 저기 있으니 **GET**으로 가라"는 뜻이라 PRG에 맞다: `RedirectResponse(url, status_code=303)`
- 다음엔 서버 로그에서 `POST ... 303` 바로 다음 줄에 `GET ... 200`이 이어지는지로 확인한다
